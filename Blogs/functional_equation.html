2Functional Equations

We go tangent a bit and look at the problem of sum of two squares. We will introduce the Jacobi theta function in this section, which motivates Riemann to derive the functional equation of the zeta function \(\zeta(s)\).

2.1Sum of two squares

People were interested in studying which positive integers can be written as a sum of squares. In the 1600s, Pierre de Fermat proved the following result on the sum of two squares

Theorem 2.1 (Fermat's theorem on sums of two squares).

Let \(p\) be an odd prime. Then \(p\) can be expressed as a sum of two squares if and only if \(p = 1\mod 4\). That is, there exist \(x,y\in\Z\) such that \(p=x^2+y^2\) if and only if \(p=1\mod 4\). More generally, let \[s(n) := \{(a,b)\in\Z^2: a^2 + b^2 = n\}\] to be the number of ways \(n\) is a sum of two squares. Then \(s(n) = d_1(n) - d_3(n)\), where \(d_i(n) =\) number of \(d\mid n\) such that \(d=i\mod 4\) for \(i\in\{1,3\}\).

Example 2.2.

Take \(n = 385 = 5 \cdot 7\cdot 11\). Note \(5 = 1\mod 4\) and \(7 = 11 = 3\mod 4\), so it has more prime divisors that are 3 mod 4. By the theorem above, it cannot be expressed a sum of two squares.

There are several proofs to this problem, and mainly fall into three categories.

1. Elementary method. This is the proof due to Fermat. For more details on this, see [Kou]

2. Algebraic method. We briefly outline the proof for those who know some algebraic number theory. Readers who are not familiar with this can skip this part without problems. The key is to realize \(x^2+y^2\) as the norm of the ideal \((x+iy)\) in the algebraic number field \(\Q(i)\). In general for a number field \(K/\Q\) with ring of integer \(\O_K\) and a nonzero ideal \(I\subseteq\O_K\), it is known that \(\O_K/I\) is a finite ring. We thus define the the norm of \(I\) to be \(N(I) := |\O_K/I|\). In our case \(K = \Q(i)\), it turns out that \(\O_K = \Z[i]\) and \(\Z[i]\) is a PID. In this case every ideal \(I\) is generated by \(a+ib\) for some \(a,b\in\Z\), and \[N((a+ib)) = a^2 + b^2\] Hence, this translates our original question to “which primes \(p\) can be the norm of an ideal in \(\Z[i]\)?”. We introduce the Dedekind zeta function of \(\Q(i)\) as \[\zeta_{\Q(i)} := \sum_{0\neq I\subseteq\O_K} \frac{1}{N(I)^s} = \sum_{n\ge 1} \frac{r(n)}{n^s}\] where \(r(n) := \#\) of ideals \(I\subseteq\O_K\) with \(N(I) = n\). Now, it turns out, using the Euler product of \(\zeta_{\Q(i)}(s)\), that \[\zeta_{\Q(i)}(s) = \zeta(s)L(s,\chi_4)\] where \(\chi_4\) is the unique non-trivial character mod 4. Therefore \[r(n) = \sum_{d\mid n} \chi(d)\] by the multiplication rule of Dirichlet series. We are not quite done yet. We have figured out an explicit formula for \(r(n)\), but this is not quite the number of ways \(n\) is a sum of two squares. For example, we note that \(25 = 3^2 + 4^2\). This actually gives four ways to write \(25\) as a sum of two squares \[25 = 3^2 + 4^2 = (-3)^2 + 4^2 = 3^2 + (-4)^2 = (-3)^2 + (-4)^2\] However, as ideals we have \[(3+4i) = (-3+4i) = (4+3i) = (-4+3i)\] This ideal is only counted once by \(r(25)\), but it represents four ways to express 25 a sum of two squares. Hence the number \(r(25)\) undercounts the number of ways \(25\) is a sum of two squares, by a factor of 4. This is actually true in general for all \(n\) (the reason is \(\Z[i]\) has four units). Hence \[s(n) = 4r(n) = 4\sum_{d\mid n} \chi_4(d)\] We know that \[\chi_4(n) = \begin{cases} 1 &\text{ if $n = 1\mod 4$}\\ -1 &\text{ if $n = 3\mod 4$}\\ 0 &\text{ otherwise} \end{cases}\] This completes the proof of Fermat’s theorem.

2.2Theta function and the Possion summation formula

3. Analytic method. This is the method that we will pay the most attention to. Again, let’s using the method of a generating function. It is natural to consider the function \[f(q) = \sum_{n\in\Z} q^{n^2}\] Then by the rule of multiplication of power series, we get \[\begin{aligned} f(q)^2 &= 1 + \sum_{n\ge 1} s(n)q^n \end{aligned}\] This works nicely as formal power series, but we cannot go further from here. The genius thought of Jacobi to consider a change of variable \(q = e^{\pi i\tau}\), where \(\Im(\tau) > 0\). This yields \[\vartheta(\tau) := f(e^{\pi i\tau}) = \sum_{n\in\Z} e^{\pi i n^2\tau}\] called the Jacobi theta function. Now we need a bit of result from Fourier analysis. For a “nice” function \(f:\R\to\R\) that we can do fourier analysis (the Schwarz class function), define \[\hat f(t) := \int_{-\infty}^\infty f(x)e^{-2\pi itx}\ \mr{d}x\] to be the fourier transform of \(f\). An amazing theorem from Fourier analysis states

Theorem 2.3 (Possion summation formula).

Let \(f\in L^1(\R)\) and the suppose that \[F(v) := \sum_{n\in\Z} f(n+v)\ \text{ converges absolutely and uniformly as a function.} \tag{1}\] and that \[\sum_{m\in\Z} |\hat f(m)| < \infty \tag{2}\] Then \[F(v) = \sum_{n\in\Z} f(n+v) = \sum_{n\in\Z} \hat f(n) e^{2\pi inv} \tag{3}\] In particular if \(v = 0\) we have \[\sum_{n\in\Z} f(n) = \sum_{n\in\Z} \hat f(n) \tag{4}\]

Proof. This is a very natural theorem if you think about it. We know a lot about the fourier analysis of periodic functions. So if we have a function \(f\in L^1(\R)\) that is not necessarily periodic, we can “periodify” it in the most natural way by equation (1). Now \(F(v)\) is 1-periodic, so we can then use the fourier analysis of periodic functions to study \(F(v)\). Condition (2) ensures that the fourier series of \(F(v)\) converges back to the \(F(v)\), that is \[F(v) = \sum_{n\in\Z} \hat F(n) e^{2\pi inv}\] Now one can check that \(\hat F(n) = \hat f(n)\), so we have proven (3).0◻

In most cases part (4) of the Possion summation formula is the one we will be using.

Example 2.4.

For the function \(v(x) = e^{-\pi x^2}\), it is a classical result that \(\hat v(t) = e^{-\pi t^2}\). So this is a function whose fourier transform it itself!

Now back to the theta function, we have \[\vartheta(\tau) = \sum_{n\in\Z} e^{\pi i n^2\tau}\] and the R.H.S reminds us of the Possion summation formula and the above Example 2.4! So why don’t we apply the Possion summation formula to it? We first make the funtion \(\vartheta(\tau)\) real-valued by the following substitution \[\omega(x) := \vartheta(ix) = \sum_{n\in\Z} e^{-\pi n^2 x}\] where \(x > 0\). For such a fixed \(x > 0\), we set \(f(y) = e^{-\pi y^2 x}\), we have \[\begin{aligned} \hat f(n) &= \int_{-\infty}^\infty e^{-\pi y^2 x} e^{-2\pi iny}\ \mr{d}y\\ &= \int_{-\infty}^\infty e^{-\pi(y\sqrt{x})^2} e^{-2\pi iny}\ \mr{d}y\\ &= x^{-1/2}\int_{-\infty}^\infty e^{-\pi u^2} e^{-2\pi i(n/\sqrt{x}) u} \qquad \text{(let }u=y\sqrt{x}\text{)}\\ &= x^{-1/2}\ \hat v\lb\frac{n}{\sqrt{x}}\rb \end{aligned}\] where \(v(x) = e^{-\pi x^2}\) is from Example 2.4 above. Hence \(\hat v(n/\sqrt{x}) = v(n/\sqrt{x}) = e^{-\pi n^2/x}\). Therefore by the Possion summation formula we obtain:

Theorem 2.5 (Functional equation of \(\omega(x)\)).

For \(x > 0\) we have \[\omega(x) = \sum_{n\in\Z} e^{-\pi n^2 x} = \sum_{n\in\Z} x^{-1/2} e^{-\pi n^2/x} = x^{-1/2}\omega\lb\frac{1}{x}\rb\]

We now use this result to obtain a functional equation of \(\vartheta(\tau)\). First we have \[x^{1/2}\vartheta(ix) = \vartheta(i/x)\] for \(x > 0\). This is a functional relation for \(\theta(\tau)\) on the upper imaginary axis, that is \[(-i\tau)^{1/2}\vartheta(\tau) = \vartheta\lb\frac{-1}{\tau}\rb\] Both sides of this equality define analytic functions on \(\mb H = \{z\in\C: \Im(z) > 0\}\), and they agree on \(\{ix: x > 0\}\subseteq\mb H\), a subset of \(\mb H\) that has limit points. Hence the identity theorem from complex analysis shows that

Theorem 2.6 (Functional equation of \(\vartheta(\tau)\)).

For all \(\tau\in\mb H\) we have \[(-i\tau)^{1/2}\vartheta(\tau) = \vartheta\lb\frac{-1}{\tau}\rb\]

Recall that we also know \(\vartheta(\tau+1) = \vartheta(\tau)\). Now we need a big black box here. By adapting the theory of modular forms, one can show that \(\vartheta(2\tau)^2\) is a weight 1 modular form of level \(\Gamma_0(4)\) and character \(\chi_4\), the unique nontrivial character mod 4 that we have seen above. The space of such modular forms have dimension 1 and is generated by some Eisenstein series. A bit of work shows that \[\theta(2\tau)^2 = 1 + \sum_{n\ge 1} \lb 4\sum_{d\mid n} \chi_4(d)\rb e^{2\pi i n^2}\] Matching the coefficients gives us Fermat’s theorem again!

2.3Functional Equation of \(\zeta(s)\)

Hopefully the above disucssion on \(\omega(x)\) looks natural enough. Now we will use the functional equation of \(\omega(x)\) to derive a functional equation of \(\zeta(s)\). We first outline a wrong proof that looks right. This nevertheless gives us a good intuition and encourages us to try to fix it and get a correct proof. First, let’s compute the Mellin transform of \(\omega(x)\) \[\begin{aligned} (\mc M\omega)(y) &:= \int_0^\infty \omega(x)x^{y-1}\ \mr{d}x\\ &= \int_0^\infty \omega(1/x) x^{1-y} \frac{\mr{d}x}{x^2} \qquad \text{(substitute }x\mapsto 1/x\text{)}\\ &= \int_0^\infty x^{1/2}\omega(x) x^{-1-y}\ \mr{d}x \qquad \text{(functional equation)}\\ &= \int_0^\infty \omega(x) x^{(1/2-y)-1}\\ &= (\mc M\omega)(1/2-y) \end{aligned}\] This gives a functional equation for the Mellin transform \(\mc M\omega\).

Remark 2.7.

The problem here is that the integral in the Mellin transform of \(\omega\) does even converge! But let’s ignore this for now lol.

Let’s compute the Mellin transform in a different way \[\begin{aligned} (\mc M\omega)(y) &= \int_0^\infty \sum_{n\in\Z} e^{-\pi n^2 x} x^{y-1}\ \mr{d}x\\ &= \sum_{n\in\Z} \int_0^\infty e^{-\pi n^2 x} x^{y-1}\ \mr{d}x \qquad \text{(by absolute convergence)}\\ &= \sum_{n\in\Z} \pi^{-y} n^{-2y} \int_0^\infty e^{-u} u^{y-1}\ \mr{d}u \qquad \text{(let }u=\pi n^2x\text{)}\\ &= \sum_{n\in\Z} \pi^{-y} n^{-2y} \Gamma(y)\\ &= \pi^{-y} \Gamma(y) \sum_{n\in\Z} n^{-2y} \qquad (*) \end{aligned}\] Note the summation here is kinda like the zeta function, if we do a change of variable \(s = 2y\), then we have \[(\mc M\omega)\lb\frac{s}{2}\rb = \pi^{-s/2}\Gamma\lb\frac{s}{2}\rb\sum_{n\in\Z} n^{-s}\] Functional equation of \(\mc M\omega\) gives \(\mc M\omega(s/2) = \mc M\omega((1-s)/2)\), so we obtain \[\pi^{-(1-s)/{2}}\Gamma\lb\frac{1-s}{2}\rb\sum_{n\in\Z} n^{-(1-s)} = \pi^{-s/2}\Gamma\lb\frac{s}{2} + 2\rb\sum_{n\in\Z} n^{-s}\] This gives a functional equation \[\pi^{-(1-s)/{2}}\Gamma\lb\frac{1-s}{2}\rb\tilde\zeta(1-s) = \pi^{-s/2}\Gamma\lb\frac{s}{2}\rb\tilde\zeta(s)\] for \(\Re(s) > 1\), related to the fake zeta function \(\tilde\zeta(s) := \sum_{n\in\Z} n^{-s}\) that kinda looks like \(\zeta(s)\), but it is hard to relate it to the actual \(\zeta(s)\) in an obvious way. Spoiler: This is actually exactly the same as the actual functional equation of \(\zeta(s\)), just \(\tilde\zeta(s)\) is replaced by \(\tilde\zeta(s)\).

Now of course the above derivation is garabage, because even the first step is wrong. We can make \(\zeta(s)\) appear in \((*)\) by replacing the sum over \(\Z\) to sum over \(\N\) by using the function \[\Omega(x) := \frac{\omega(x)-1}{2} = \sum_{n\ge 1} e^{-\pi n^2 x}\] The Mellin transform of \(\Omega(x)\) now exists! The above derivation also tells us that we should compute its Mellin transform at \(s/2\), for \(\Re(s) > 1\).

Hopefully the explanation above motivates what we are trying to do, so let’s begin the formal and rigorous treatment of the functional equation. By similar computations from above \[\begin{aligned} (\mc M\Omega)(s/2) = \int_0^\infty \Omega(x)x^{s/2-1}\ \mr{d}x = \int_0^\infty \sum_{n\ge 1} e^{-\pi n^2 x} x^{s/2-1}\ \mr{d}x = \pi^{-s/2}\Gamma(s/2)\zeta(s) \end{aligned}\] We now define \(\Lambda(s) := \pi^{-s/2}\Gamma(s/2)\zeta(s)\) for \(\Re(s) > 1\). Since \(2\Omega(x) + 1 = \omega(x)\), we know \(\Omega(x)\) has a functional equation (coming from \(\omega(x)\)) that \[\Omega(x) = x^{-1/2}\Omega(1/x) + \frac{1}{2}(x^{-1/2}-1)\] for \(x > 0\). Just like \(\omega(x)\), this translates the information about \(\Omega(x)\) for \(x\in(0,1)\) to \(\Omega(x)\) for \(x\in(1,\infty)\) and vice verse. Hence we can consider \[\begin{aligned} \Lambda(s) &= \pi^{-s/2}\Gamma(s/2)\zeta(s) = \int_0^\infty \Omega(x)x^{s/2-1}\ \mr{d}x\\ &= \int_0^1 \Omega(x)x^{s/2-1}\ \mr{d}x + \int_1^\infty \Omega(x)x^{s/2-1}\ \mr{d}x\\ &= \underbrace{\int_0^1 (x^{-1/2}\Omega(1/x) + \tfrac{1}{2}(x^{-1/2}-1))x^{s/2-1}\ \mr{d}x}_{(\dagger)} + \int_1^\infty \Omega(x)x^{s/2-1}\ \mr{d}x\\ &= \int_0^1 \Omega(x)x^{(1-s)/2-1}\ \mr{d}x + \frac{1}{s-1} - \frac{1}{s} + \int_1^\infty \Omega(x)x^{s/2-1}\ \mr{d}x \qquad \text{(substitute }x\mapsto 1/x\text{ in }(\dagger)\text{)} \end{aligned}\] Now the magic occurs! We see that in the last expression, if we replace \(s\) with \(1-s\), we actually get the same expression back! Moreover, note that this expression is valid for any \(s\in\C\) with \(s\neq 0,1\). We can then think of it as an analytic continuation of \(\Lambda(s)\) to \(\C\setminus\{0,1\}\) such that \(\Lambda(s) = \Lambda(1-s)\).

Theorem 2.8.

On the region \(\C\setminus\{0,1\}\) \[\Lambda(s) := \int_0^1 \Omega(x)x^{(1-s)/2-1}\ \mr{d}x + \frac{1}{s-1} - \frac{1}{s} + \int_1^\infty \Omega(x)x^{s/2-1}\ \mr{d}x\] defines an analytic function with poles at \(0\) and \(1\). Moreover it satisfies \(\Lambda(s) = \Lambda(1-s)\) for all \(s\neq 0,1\). If \(\Re(s) > 1\) we have \(\Lambda(s) = \pi^{-s/2}\Gamma(s/2)\zeta(s)\). Therefore we get a functional equation of the Riemann zeta function \[\pi^{-s/2}\Gamma(s/2)\zeta(s) = \pi^{-(1-s)/2}\Gamma((1-s)/2)\zeta(1-s)\]

This theorem is very powerful. Note that \(1-s = s\) if and only if \(s = 1/2\). This means the information of \(\zeta(s)\) for \(\Re(s) < 1/2\) can be studied using the information \(\Re(s) > 1/2\). In particular we can study \(\Re(s) < 0\) using \(\Re(s) > 1\), which we know quite well!
